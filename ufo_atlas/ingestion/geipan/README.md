# GEIPAN source ingestion for the central UFO Atlas

This directory stages GEIPAN source material for incorporation into the single central Watchers Project UFO Atlas.

GEIPAN is represented as a source and provenance system. It does not control the Atlas taxonomy, canonical identity, public hierarchy, or adjudication. No separate public GEIPAN database is created.

## Controlling architecture

- UFO Atlas pilot database and Watchers Project UFO Atlas Integration Standard control record structure.
- The GMR contributes metadata governance, field provenance, explicit applicability and missingness, controlled terms, validation, and release discipline.
- Original French source labels, values, identifiers, source order, and documents must be preserved.
- English translations and normalized values must remain separate from the original French source data.
- GEIPAN classifications must be stored as attributed source claims, not adopted as Atlas conclusions.
- Canonical Atlas identifiers are allocated only by the central master after duplicate and identity adjudication.

## Current work package

1. Acquire and hash the official machine-readable exports and supporting documentation.
2. Preserve every source table, column, row, and original value in an immutable source ledger.
3. Construct the bilingual field crosswalk to the UFO Atlas metadata registry.
4. Generate source-neutral candidate records and typed relationships.
5. Match against the current central Atlas and enrich existing records rather than duplicating them.
6. Validate source coverage, metadata decisions, provenance, chronology, relationships, and reproducibility before handoff.
