# Watchers Project UFO Atlas

## What this project is

A standalone novelty exercise: a free, searchable UFO collection for browsing, curiosity, and entertainment. It is not a Domain Science database, a scientific adjudication system, or a module that must plug into another Atlas.

The assistant is responsible for creating and maintaining this project's own ordinary database and import structure. An external master, Domain Science GMR, scientific-conformance migration, six-sided model, or outside integration approval is not required. Do not ask the owner to supply a nonexistent master.

This owner clarification supersedes the external-registry requirement recorded in older preparation reports. Keep those old reports as historical records; their missing-GMR warning is not an active blocker.

## Keep the useful content requirements

- Cases, people, reported beings, objects, organizations, places, documents, media, and their useful connections belong in one source-neutral collection. GEIPAN, Blue Book, and other archives identify sources, not competing public database structures.
- Preserve source records, source identifiers, original wording, and links. Keep ambiguous matches separate rather than merging by guesswork. Do not reverse source anonymization.
- Write readable case stories in reported event order. Keep later recollection methods and source explanations identifiable; do not pass source text, an unfinished story, or an allegation off as a completed or established account.
- Use ordinary search and filters, with no embedded AI or paid search dependency.

## Current work

Continue GEIPAN acquisition and import preparation using the existing saved records. Do not restart an active download or discard previous work. Missing supplemental downloads remain individual pending or failed files; they do not make the entire case catalogue unusable. Completed stories and supplemental-file coverage are separate from whether source records can be loaded into the standalone database.

A practical schema, stable IDs, source links, non-destructive updates, and basic data-integrity checks are sufficient. They are implementation details, not a Domain Science framework.
